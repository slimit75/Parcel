# Parcel
Parcel is a GitHub Action designed to simplify the distribution of add-on aircraft for X-Plane using the [SkunkCrafts Updater](https://forums.x-plane.org/index.php?/forums/forum/406-skunkcrafts-updater/).

> [!NOTE]
> If you are looking for the older Python script version, please check out the '[main](https://github.com/slimit75/Parcel/tree/main)' branch. (it is not the main branch, but that is it's name for backwards-compatibility reasons for the moment)

> [!WARNING]
> This project is provided as-is and may break at any time. This project was developed without input from the original developers of the SkunkCrafts Updater, and this project should not be confused for anything officially endorsed.
