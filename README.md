# Parcel
Parcel is a GitHub Action designed to simplify the distribution of add-on aircraft for X-Plane using the [SkunkCrafts Updater](https://forums.x-plane.org/index.php?/forums/forum/406-skunkcrafts-updater/).

> [!NOTE]
> If you are looking for the older Python script version, please check out the [legacy_py_script](https://github.com/slimit75/Parcel/tree/legacy_py_script) branch.

> [!WARNING]
> This project is provided as-is and may break at any time. This project was developed without input from the original developers of the SkunkCrafts Updater, and this project should not be confused for anything officially endorsed.

## Usage
> [!IMPORTANT]
> This project is a work in progress, and documentation is admittedly lacking at the moment. At the same time, things 
are not yet stable. If you need something *slightly* more proven, please check out the Python script above. Otherwise, if you have any questions,
please feel free to reach out over Discord (`@slimit75`) or Matrix (`@slimit75:matrix.org`).

Please read the [wiki](https://github.com/slimit75/Parcel/wiki) for information about usage and file specifications.
